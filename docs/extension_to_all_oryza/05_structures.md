# Step 5 — structural modelling: reporting checklist (not re-run here)

Your `3d model/` and `Structure/` folders already contain SWISS-MODEL output; I did not
re-run or re-validate these (no network access in this sandbox) and have not copied
unverified structural claims into the report. Before using any of these models in the
manuscript, confirm each one reports:

- Template PDB ID(s) used
- Sequence identity to template
- Template coverage (% of query modelled)
- GMQE (Global Model Quality Estimate)
- QMEAN (and QMEANDisCo if available)
- Which regions are NOT modelled (low-confidence / missing loops) — state this explicitly,
  don't just show the confident core

Per the earlier review: keep this section secondary (one Type I + one Type II
representative structure in the main text, the rest in Supplementary), and avoid functional
claims like "structural variations may reflect functional diversification" unless you have
independent evidence (e.g. a known functional difference between the two paralogs) to
support it — a structural model alone does not establish function.
